# Zrzuty interfejsu

Wykonane 11 października 2026 w rzeczywistej aplikacji Streamlit, w oddzielnej
kopii projektu z nowym środowiskiem Python. Bez `.env`, prywatnej historii,
importowanych baz, klucza API i wywołań modelu. Nie edytowano treści interfejsu
na potrzeby zrzutów. Widoczne wartości pochodzą z syntetycznej bazy e-commerce.

| Plik | Widok | Odtworzenie |
| --- | --- | --- |
| `screenshots/01-start.jpg` | Ekran startowy | Uruchom czystą kopię bez klucza API |
| `screenshots/02-wyniki.jpg` | Rozmowa i tabela | Kliknij „Przychód miesięczny” i przewiń do tabeli |
| `screenshots/03-schemat-ai.jpg` | Schemat bez rekordów | Otwórz „O danych” → „Schemat dla AI” |

Pierwszy start tworzy demo e-commerce automatycznie. Wbudowany przykład wykonuje
stałe, walidowane SQL lokalnie; pokazuje wygląd i obsługę aplikacji, a nie ocenę
jakości modelu. Mikrofon widoczny na zrzutach nie był aktywowany.

Zrzuty są zasobami dokumentacji i można je odtworzyć bez płatnego API.
Nie dodawaj tu zdjęć panelu kluczy, prywatnych rozmów ani danych z cudzych baz.
